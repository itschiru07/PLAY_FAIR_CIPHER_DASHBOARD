The Three Rules

Same Row

Encrypt: letter to the right.
Decrypt: letter to the left.

Wraps from the last column to the first.
Same Column

Encrypt: letter below.
Decrypt: letter above.

Wraps from the bottom row to the top.
Rectangle

Each letter keeps its row and takes the other letter's column.

Same for encryption and decryption.

Square Alphabet (I / J merged)

The square holds 25 cells, so J is merged with I. Key letters (highlighted) are placed first without repeats, then the rest of the alphabet in order.
